# Radar de Licitações

Consulta e filtra licitações com **propostas abertas** no Brasil, com dados do [PNCP](https://pncp.gov.br) (CC BY 4.0).

- **Site:** GitHub Pages lendo `data/licitacoes.json`.
- **Coleta:** `atualizar.py`, rodado pela Action *Atualizar licitações* 3x por dia (06h, 12h, 18h de Brasília) ou manualmente em *Actions → Run workflow*.
- **extensao-chrome/:** versão extensão que consulta o PNCP ao vivo (carregar sem compactação em `chrome://extensions`).

Sempre confira o edital e a plataforma de disputa antes de enviar proposta.
